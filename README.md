## Overview

**Nexus OS** is a productivity dashboard built with vanilla HTML, CSS, and JavaScript. It combines a task board, calendar, and focus timer in one responsive interface, with progress feedback designed to make everyday planning feel more engaging.

## Highlights

- **Kanban task management:** Create, edit, delete, and organize tasks across Not Started, In Progress, and Completed columns. Drag tasks between statuses.
- **Priorities and categories:** Organize work with priority levels, due dates, and Work, Personal, and Health categories.
- **Focus mode:** Use a dedicated Pomodoro-style timer for focused work sessions.
- **Calendar view:** Review tasks by date and get a clearer picture of upcoming work.
- **Progress insights:** Track pending, completed, and overdue tasks alongside a productivity score.
- **Gamified progress:** Earn experience points, level up, and keep an eye on your activity streak.
- **Personalized interface:** Switch between dark and light themes, search tasks, and use the responsive layout across screen sizes.
- **Local persistence:** Tasks, profile details, and theme preferences are saved in browser localStorage.

## Technology

| Area | Implementation |

| Structure | HTML5 |

| Visual effects | Canvas particle animation |
| Icons and typography | Phosphor Icons and Plus Jakarta Sans |

## Run Locally

No build step or package installation is required for the core application.

1. Clone or download this repository.
2. Open index.html in a modern browser.
3. Start creating tasks and exploring the dashboard.

Fonts and icon assets are loaded from external CDNs, so those visual assets require an internet connection.

## Data and Limitations

Nexus OS stores its working data in the current browser using localStorage. It does not provide cloud synchronization or shared accounts, so saved tasks do not automatically follow you to another browser or device. Clearing the browser's site data may remove locally saved progress.
